# Control LED Button

## Deskripsi

Project Arduino Uno untuk mengontrol
satu LED menggunakan satu push button.

## Hardware

- Arduino Uno
- 1 LED
- 1 Push Button
- 1 Resistor 220 Ohm
- Breadboard
- Jumper Wire

## Pin Configuration

- LED: D8
- Button: D2

## Cara Kerja

Ketika tombol ditekan, LED menyala.
Ketika tombol dilepas, LED mati.
