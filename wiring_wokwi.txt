====================================================
KONFIGURASI WIRING ESP32 - 3 LED & 3 PUSH BUTTON
====================================================

1. LED 1 (Merah):
   - Kaki Anoda (+)  -> Resistor 220 Ohm -> Pin GPIO 18
   - Kaki Katoda (-) -> Pin GND

2. LED 2 (Biru):
   - Kaki Anoda (+)  -> Resistor 220 Ohm -> Pin GPIO 19
   - Kaki Katoda (-) -> Pin GND

3. LED 3 (Kuning):
   - Kaki Anoda (+)  -> Resistor 220 Ohm -> Pin GPIO 21
   - Kaki Katoda (-) -> Pin GND

4. Push Button 1:
   - Kaki 1 (1.l)    -> Pin GPIO 4 (Mode INPUT_PULLUP)
   - Kaki 2 (2.r)    -> Pin GND

5. Push Button 2:
   - Kaki 1 (1.l)    -> Pin GPIO 5 (Mode INPUT_PULLUP)
   - Kaki 2 (2.r)    -> Pin GND

6. Push Button 3:
   - Kaki 1 (1.l)    -> Pin GPIO 15 (Mode INPUT_PULLUP)
   - Kaki 2 (2.r)    -> Pin GND
